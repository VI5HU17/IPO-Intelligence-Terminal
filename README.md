# IPO-Intelligence-Terminal
"An automated, real-time IPO Intelligence Terminal designed to track the Indian market. This project leverages Python and Streamlit to dynamically scrape live subscription data and Grey Market Premiums (GMP), providing logic-driven investment verdicts and retail allotment probability analysis."

## 🌟 Key Features
*   **Live Data Automation:** Scrapes real-time subscription data from major Indian market trackers.
*   **Intelligent Verdicts:** Logic-based categorization: 'Rocket', 'Steady', or 'Cautious'.
*   **Allotment Probability Engine:** Calculates retail investor odds based on live demand.
*   **Zero-Maintenance:** Self-cleaning system that updates as new IPOs arrive.

## 🛠️ Technical Stack
*   **Language:** Python
*   **Framework:** Streamlit
*   **Libraries:** Pandas, Requests, BeautifulSoup4, LXML
*   **Deployment:** Streamlit Community Cloud
